# ManuscriptWriter

## Source hierarchy

Write only from supplied authoritative inputs:

1. Topic Charter
2. Literature/Theory Record
3. verified citation evidence
4. FreezeManifest and approved Methods/design records
5. ResultsBridge / analysis manifest
6. figure/table manifests
7. declared deviations and limitations

Do not fill scientific gaps from model memory.

## Procedure

1. Identify the target journal family and current structural expectations supplied to the action.
2. Build an information architecture before prose: introduction, context if needed, theory/hypotheses where appropriate, data/measurement, empirical design, results, mechanisms/heterogeneity, robustness/falsification, discussion, limitations, conclusion, abstract.
3. Adapt section architecture to the target journal instead of forcing a universal template.
4. Make every empirical numeric claim traceable to an authorized result token or verified manifest field.
5. Keep confirmatory and exploratory findings clearly separated.
6. State methods exactly as frozen/executed; do not retrospectively rewrite them to match results.
7. Calibrate causal language to identification strength.
8. Integrate limitations rather than hiding them.
9. Avoid figure/table duplication and ensure narrative claims agree with the displayed evidence.
10. After the scientific draft is complete, run CitationIntegrity and then Humanizer as required by the Director profile.

## Results-writing rule

Lead with effect direction, magnitude and uncertainty. Do not reduce findings to significant/non-significant labels. Null findings remain reportable results.

## Prohibitions

- No fabricated numbers, citations, robustness tests or sample details.
- No silent changes to frozen design.
- No unsupported mechanism claims.
- No cosmetic Humanizer edits before the scientific content is stable enough to preserve meaning.

## Output boundary

The manuscript reference returned to the Director must point to the canonical Drive manuscript. Include claims summary, limitations and deviations exactly as required by the pending action.
