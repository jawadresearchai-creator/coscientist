# V4.6 Integrity Guarantees

CoScientist v4.6 closes lifecycle gates that previously accepted reasoning-plane assertions for facts deterministic code can know. The following promises are executable contracts backed by `GUARANTEES_INTEGRITY.yaml` and regression tests.

- Dataset hashes used for design closure must come from canonical GMS dataset receipts, not model-authored strings. [GUARANTEE: DESIGN_HASHES_REQUIRE_DATASET_RECEIPT]
- Design closure requires a deterministic power receipt with `powered=true`. [GUARANTEE: DESIGN_POWER_REQUIRES_POWER_RECEIPT]
- Pre-freeze PASS is conjunctive across all mandated scientific dimensions. [GUARANTEE: PREFREEZE_PASS_IS_CONJUNCTIVE]
- Reasoning-declared external-source assertions do not close essential data feasibility. [GUARANTEE: EXTERNAL_SOURCE_ASSERTIONS_DO_NOT_CLOSE_FEASIBILITY]
- Lifecycle receipts are write-once and tamper-evident. [GUARANTEE: LIFECYCLE_RECEIPTS_ARE_WRITE_ONCE]
- `RESULTS_COMPLETE` requires the canonical analysis receipt bound to the active freeze and AnalysisLock. [GUARANTEE: RESULTS_COMPLETE_REQUIRES_ANALYSIS_RECEIPT]
- The scheduled Director cycle closes mechanical freeze/lock/analysis handoffs without LLM state mutation. [GUARANTEE: CYCLE_CLOSES_MECHANICAL_HANDOFFS]
- The analysis workflow has no historical default study identifier. [GUARANTEE: ANALYSIS_HAS_NO_HISTORICAL_DEFAULT_STUDY]
- Confirmatory analysis executes the exact Git commit supplied by the lock/dispatch boundary. [GUARANTEE: ANALYSIS_EXECUTES_LOCKED_GIT_COMMIT]
- The Drive-credential-bearing research cycle does not write to the public repository. [GUARANTEE: SECRET_BEARING_CYCLE_DOES_NOT_WRITE_PUBLIC_REPO]

These guarantees supplement, rather than replace, the earlier single-paper, Director, freeze, AnalysisLock, results-provenance and reasoning-role guarantees.
